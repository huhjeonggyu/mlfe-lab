Seoul Fintech Support Program

Selected for an industry–academia research collaboration.

2026.06.11

We have been selected as a partner institution for a Seoul Fintech Support Program project. This industry-academia collaboration project is led by RiskX, with Hanyang University and Sungkyunkwan University participating as partner institutions. The project is titled "Development of an ELS Hedging Decision-Making System Using Neural Network-Based Optimal Control".
